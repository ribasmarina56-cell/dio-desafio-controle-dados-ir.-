# 📊 Controle de Dados para Declaração de Imposto de Renda

Projeto desenvolvido em Excel para facilitar a organização das informações necessárias à preparação da declaração de Imposto de Renda.

## 🎯 Objetivo

Criar uma ferramenta prática e profissional para centralizar dados fiscais, documentos, rendimentos, pendências e observações, utilizando recursos nativos do Excel.

## 📚 Conteúdos

- Introdução
- Menu
- Menu Itens
- Criando uma função de Excel
- Formulário Titular
- Formatações personalizadas
- Tela de Informes
- Tela de Notas
- Toques Finais
- Entendendo o Desafio

## 🧩 Recursos

- Validação de dados com listas suspensas
- Navegação facilitada por menu
- Formulário para dados do titular
- Cadastro de informes de rendimentos
- Controle de documentos e status
- Registro de notas, pendências e prazos
- Formatação personalizada
- Totais e indicadores automáticos
- Gráfico para visualização dos rendimentos
- Área de configurações para listas de apoio

## 🗂️ Estrutura

| Aba | Finalidade |
|---|---|
| Introdução | Apresentação e orientações |
| Menu | Navegação principal |
| Formulário Titular | Dados cadastrais |
| Informes | Rendimentos e documentos |
| Notas | Pendências e observações |
| Configurações | Listas de validação |

## ⚠️ Observação

A ferramenta é destinada à **organização de informações** e não substitui orientação profissional, legislação tributária ou os sistemas oficiais da Receita Federal.

## 🚀 Portfólio

Este projeto demonstra a aplicação prática de recursos do Excel para criar uma solução organizada, interativa e orientada a uma necessidade real.
